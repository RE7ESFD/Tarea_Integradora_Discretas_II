##  Descripción del Proyecto

Este proyecto implementa y analiza una serie de algoritmos basados en el paradigma de **Divide y Vencerás (Divide and Conquer)** utilizando el lenguaje de programación Scala bajo las restricciones estricta del paradigma funcional.

### Problemas Abordados

1. **Problem 1: Number of Inversions **
    * **Descripción:** Determina la cantidad de pares invertidos en una secuencia dada de enteros basándose en una adaptación funcional del algoritmo *Merge Sort*.

2. **Problem 2: Improving Quick Sort (3-Way Partition)**
    * **Descripción:** Rediseño e implementación del algoritmo *Randomized QuickSort* utilizando una partición de 3 vías (`< x`, `= x`, `> x`) para mejorar sustancialmente el rendimiento en secuencias con elementos repetidos.

3. **Problem 3: Closest Points ($O(n \log n)$)**
    * **Descripción:** Algoritmo divide y vencerás para encontrar la menor distancia euclidiana entre un conjunto de $n$ puntos en el plano bidimensional en tiempo $O(n \log n)$.
